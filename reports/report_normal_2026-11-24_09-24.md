1. **التقييم وحقيقة الأداة:**

   - **حقيقتها:** مستودع قواعد رصد (Detection Rules)، مؤشرات اختراق (IOCs)، واستعلامات صيد (Threat Hunting) جاهزة للكشف عن هجمات وكلاء الذكاء الاصطناعي الهجومية (Agentic AI Frameworks مثل Agent Zero وHexStrike).
   - **الجاهزية للإنتاج:** جاهزة بالكامل للدمج الفوري في أنظمة SIEM/EDR (مثل Microsoft Sentinel, Splunk, Elastic).

2. **المجال والفئة المستهدفة:**
   - **المجال:** الأمن السيبراني الدفاعي والذكاء الاصطناعي.
   - **الفئة المستهدفة:** فرق عمليات الأمان (SOC)، مهندسو الكشف عن التهديدات (Detection Engineers)، ومزودو خدمات الأمن المُدار (MSSP).

3. **الاستغلال الربحي المباشر:**
   - **النموذج:** تقديم خدمة "حماية بيئات الذكاء الاصطناعي والوكلاء الآليين" (AI Agent Security Monitoring) كخدمة مدفوعة (Micro-SaaS أو Managed SOC) للشركات التي تطور أو تستخدم وكلاء ذكاء اصطناعي لتقليل مخاطر الاختراق الذاتي.

4. **اختصار مدة العمل:**
   - **المهمة الملغاة:** كتابة قواعد الكشف وصيغ الاستعلامات يدوياً (KQL, Sigma, YARA) لتحليل سلوكيات الهجمات الموجهة بالذكاء الاصطناعي.
   - **توفير الوقت:** توفر ما يقدر بـ **120 إلى 160 ساعة عمل** هندسية لكل منصة رصد مستهدفة.

5. **الاستخدام العملي والحياتي:**
   - **السيناريو:** يقوم مهندس SOC بربط قواعد المستودع بـ Microsoft Sentinel لديه، فتقوم النظام فوراً باكتشاف وتنبيه الفريق إذا حاول أحد وكلاء الذكاء الاصطناعي الداخليين (أو المهاخمون) تنفيذ إطار عمل هجومي مثل "Agent Zero" داخل شبكة الشركة، مما يمنع الاختراق الذاتي الموجه.

6. **خطوات التشغيل الفورية:**
   1. استنساخ المستودع: `git clone https://github.com/ThreatDefence/agentic-attack-detections.git`
   2. تصفح مجلد `deploy/` أو استخراج قواعد `Sigma` / `KQL` الخاصة بمنصة التحليل لديك (مثل Splunk أو Sentinel).
   3. استيراد القواعد مباشرة إلى منصة SIEM الخاصة بك وتفعيل تنبيهات المؤشرات (IOCs) المستخرجة.

   - لا يوجد استغلال ربحي مشروع؛ الأداة مصممة لسرقة بيانات المستخدمين والمحافظ الرقمية (Stealer) عبر الملف التنفيذي الملغوم، وليست أداة Micro-SaaS صالحة للاستخدام.

4. **اختصار مدة العمل:** 
   - لا توفر أي وقت؛ بل تتسبب في خسارة كاملة للبيانات والأصول المالية في حال تشغيل الملف التنفيذي المرتبط بها.

5. **الاستخدام العملي والحياتي:** 
   - **تحذير صارم:** لا توجد سيناريوهات استخدام آمنة لهذا المستودع. استخدامه الوحيد في بيئة اختبارية معزولة (Sandbox) هو لتحليل البرمجيات الخبيثة (Malware Analysis) فقط.

6. **خطوات التشغيل الفورية:** 
   - (1) **تجنب تماماً** تحميل الملف المضغوط أو إدخال كلمة المرور `2026`.
   - (2) **لا تقم مطلقاً** بتشغيل الملف التنفيذي (`.exe`) على أي جهاز يحتوي على محافظ عملات رقمية أو بيانات حساسة.
   - (3) الإبلاغ عن المستودع فوراً لمخالفته معايير الأمان ونشر برمجيات خبيثة (Malware/Phishing).
